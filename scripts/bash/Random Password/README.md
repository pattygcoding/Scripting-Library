# Random Password

Generate a random password using a mix of letters, digits, and symbols.

## Dependencies

- `tr` and `/dev/urandom`

## Parameters

- `$1` - Password length (optional, defaults to `12`)

## Usage

```bash
random-password [length]
```

## Example

```bash
random-password 24
# Output: aB3$kL9!pQ2&zX7@wR4*nM8-
```

# Unit Tests

Clean, build and test a .NET unit test project with `dotnet clean`, `dotnet build`, and `dotnet test`.

## Dependencies

- .NET SDK (`dotnet`)

## Parameters

- `$1` - Path to the `.csproj` to test (required)

## Usage

```bash
unit-tests <path-to.csproj>
```

## Example

```bash
unit-tests MyProject.Tests.csproj
```
